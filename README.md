# WoodShed

Guitar practice — rhythm, scales, chord theory, and voicing exercises.

A React + Vite app for practicing scales, chord progressions, and voicings across the fretboard. Runs entirely client-side with no backend, and installs as a PWA on iPhone for full-screen, offline use.

## Development

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

`npm run preview` serves the production build at `http://localhost:4173/woodshed/` (the app is configured with base path `/woodshed/` to match its GitHub Pages URL).

## App icons

The home screen / PWA icons are generated by script rather than stored as static art:

```bash
npm run generate-icons
```

This runs [scripts/generate-icons.js](scripts/generate-icons.js) (using the `canvas` package) and writes `public/icons/icon-192.png` and `public/icons/icon-512.png`. Edit that script to change the icon design, then re-run it.

## Installing on iPhone

1. Open Safari and go to the live site: https://csilveira303.github.io/woodshed
2. Tap the Share button
3. Tap **Add to Home Screen**, then **Add**

WoodShed launches full screen with no browser chrome and works fully offline (a service worker precaches the app on first load).

## Deploying

```bash
npm run deploy
```

This regenerates icons, builds, and publishes `dist/` to the `gh-pages` branch, which GitHub Pages serves at https://csilveira303.github.io/woodshed. Allow a couple of minutes for the Pages build to finish after deploying.
